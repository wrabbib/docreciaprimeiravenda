# Do CRECI à primeira venda

Guia online para corretores de imóveis: direitos, deveres, documentos, comissão e cada etapa da venda.

- Next.js (App Router) + Supabase (login, conteúdo e progresso)
- Conteúdo das aulas e cards fica no banco (tabelas `modulos`, `aulas`, `quiz_perguntas`, `cards`)
- Deploy automático no Vercel a cada push na `main`
